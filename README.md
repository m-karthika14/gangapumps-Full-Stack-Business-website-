Ganga Pumps – Full Stack Business Website

Ganga Electrical and Hardwares is a top-rated water pump and hardware store based in Bangalore. This website brings their entire shop online with a fully functional, mobile-friendly platform for showcasing products, collecting customer leads, displaying reviews, and managing everything through a dedicated admin dashboard.

## Tech Stack
Frontend: React (Vite) and Tailwind CSS
Backend: Node.js and Express.js
Database: MongoDB (Cloud – Atlas)
Hosting: Vercel for fontend and Render for backend
Domain: Namecheap
Email: Zoho Mail (Receiving) and Resend API (Sending)
Monitoring: UptimeRobot (Pinged every 5 minutes to prevent cold starts)

## Key Features
Admin Dashboard
  - Add, update, and delete products
  - Approve and manage reviews
  - Track customer leads with timestamps

Product Showcase
  - Categorized listings with images, features, and brand details

Customer Reviews
  - Submit & manage testimonials or product feedback

Lead Capture
  - Estimate form and popup form
  - Integrated with Resend API to send leads to Zoho Mail

Fully Responsive
  - Seamless UX across devices

Performance Optimized
  - AVIF/WebP images, lazy loading, SEO meta tags, and fast loading times
